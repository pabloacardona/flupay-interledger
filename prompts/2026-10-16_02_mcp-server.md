## Result

- `packages/shared`: 402 contract with zod (`Payment-Required` header, `Authorization: OpenPayments <incoming>`), money helpers in minor units (bigint, no floats), AES-256-GCM, Open Payments client factory.
- `apps/agent-wallet`: Prisma schema (owners, agents, grants, payments); Flow A (interactive capped grant with GNAP hash verification, revoke, token rotation); Flow B (`paid_fetch`, `pay`, `get_balance`) over Streamable HTTP MCP; typed errors; activity feed for the demo console.
- SDK calls checked against the installed `@interledger/open-payments` 7.4.0 type definitions. Differences from the PRD: quotes require `method: "ilp"`; spent amount comes from `outgoingPayment.getGrantSpentAmounts`; the `pay` tool takes the full `Payment-Required` JSON because the public incoming payment does not expose the amount or merchant wallet.
- Smoke-tested locally with a fake 402 merchant: auth, free passthrough, `INVALID_PAYMENT_REQUIRED`, `PRICE_EXCEEDS_MAX`, `MERCHANT_NOT_ALLOWED`, `GRANT_INACTIVE`.
